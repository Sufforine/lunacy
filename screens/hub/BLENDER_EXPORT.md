# Блочный хаб

`ui/hub.tscn` — игровая сцена. `ui/hub_architecture.tscn` — отдельная редактируемая CSG-геометрия: зал, четыре стойки, четыре колонны, ворота, книга и костёр.

## Экспорт в Blender

1. Открыть `hub_architecture.tscn` в Godot, дождаться построения CSG.
2. Scene → Export As… → glTF 2.0 Scene… (в локализованном редакторе: Сцена → Экспортировать как).
3. Сохранить `.glb` или `.gltf` вне папки проекта, затем импортировать в Blender через File → Import → glTF 2.0.

Godot запекает CSG в обычные меши при экспорте. Группы имеют имена Blacksmith, Alchemist, Merchant, Engineer, Campfire, ExitGate, DungeonGate и MissionBook. Масштаб: 1 единица = 1 метр. Зал 28 × 44 м; высота потолка 10 м; створки ворот 5,4 м. Для вида сверху скрыть группу Ceiling_HideForTopView.

Можно экспортировать и весь `hub.tscn`, чтобы включить сундук и освещение. Частицы, диалоги, сетевой код, коллизии и интерактивность являются логикой Godot; glTF не заменяет их перенос. После доработки импортировать геометрию отдельной сценой и заменить только Architecture, сохранив игровые узлы и восстановив необходимые коллизии.

Книга у южных ворот открывает локальный выбор миссии. Wagon — техническое имя зоны сбора перед воротами, сохранённое для сетевых вызовов; визуальной повозки больше нет. Для запуска все игроки должны стоять в радиусе 4 м пять секунд. ExitDoor у противоположных ворот запрашивает подтверждение выхода. Ремесленные стойки пока обозначены цветом и формой, без меню ремесла.
