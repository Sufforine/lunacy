# Kenney Fantasy UI Borders

Source: Kenney Fantasy UI Borders.

`window_border.png` is `Default/Border/panel-border-009.png` and is used as the single border for large windows. Inventory slots use `Default/Panel/panel-015.png`, switching to `panel-000.png` while the left mouse button is held. Interaction prompts use `Default/Transparent border/panel-transparent-border-009.png`. `button_panel.png` is `Default/Panel/panel-009.png` and is used for ordinary buttons.
