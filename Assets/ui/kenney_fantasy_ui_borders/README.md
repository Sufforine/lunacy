# Kenney Fantasy UI Borders

Source: Kenney Fantasy UI Borders.

`panel_027.png` is `Default/Panel/panel-027.png` and provides both the dark center and decorative edge for large windows. Ordinary buttons combine `Default/Panel/panel-028.png` for their background with `Default/Border/panel-border-028.png` for a separately colored hover edge. Inventory slots use `Default/Panel/panel-015.png` with `Default/Border/panel-border-015.png` above their icons, switching both layers to variant `000` while the left mouse button is held. Interaction prompts use `Default/Border/panel-border-009.png` so their center remains transparent. World selection uses two mirrored copies of `Default/Divider Fade/divider-fade-000.png`.
